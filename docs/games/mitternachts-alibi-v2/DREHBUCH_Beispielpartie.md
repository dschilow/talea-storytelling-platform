# Drehbuch einer Beispielpartie (Mini-Detektive, 4 Spieler)

So spricht das Spiel in einer ganzen Partie. Jede Zeile ist ein Aufruf der Sprachausgabe, zusammengesetzt aus Clips aus `Stimmen.json`. **🔊 laut** spricht Kommissar Tavi (oder eine Figur) für alle, **🤫 flüstert** ist das Geheimtelefon (leise, nur am Ohr). Aufgezeichnet aus einer echten Partie des Zufallsspielers, ohne Kürzungen. Die Figuren sind jedes Mal andere.

Die geflüsterten Zeilen sind die einzigen, die private Informationen enthalten. Die lauten Aussagen sind für den Dieb und für Unschuldige gleich gebaut: Schwur der Figur, Nummer, Figur, Ort, „Dabei: …“ oder „Ganz allein.“, kurzer Abschluss.
